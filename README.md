# Keepsake — адаптивний landing page

Навчальний вебпроєкт односторінкового сайту Keepsake. Сторінка побудована з використанням Pug для HTML-розмітки, SCSS для стилізації та Vite для локальної розробки й production-збірки.

## Посилання

- **Репозиторій:** https://github.com/Bohdan7563/landing-keepsake-vite
- **Демо:** https://bohdan7563.github.io/landing-keepsake-vite/

> Демо стане доступним після успішного розгортання GitHub Pages.

## Технології

| Інструмент | Призначення |
| --- | --- |
| Pug | Створення HTML-сторінки, шаблонів, компонентів і повторюваних блоків |
| SCSS (Sass) | Організація стилів, змінних, міксинів і вкладених правил |
| Vite | Локальний сервер розробки та збирання проєкту |
| Vituum | Підключення Pug-сторінок до процесу збірки Vite |
| PostCSS + Autoprefixer | Автоматичне додавання CSS-префіксів для цільових браузерів |
| Sharp | Підготовка зображень у форматах AVIF, WebP і JPEG |
| Prettier | Єдине форматування файлів проєкту |
| Stylelint | Перевірка якості SCSS |
| Husky + lint-staged | Запуск перевірок для змінених файлів перед комітом |
| GitHub Actions | Автоматична збірка та публікація сайту на GitHub Pages |

## Вимоги

- Node.js `20.19+` або `22.12+`;
- npm `10+`.

## Запуск локально

```bash
npm install
npm run dev
```

Після запуску Vite виведе адресу локального сервера в термінал (типово `http://localhost:5173/`). Відкрий її у браузері.

## Перевірка та збірка

```bash
npm run format
npm run lint
npm run build
npm run preview
```

Команди:

| Команда | Призначення |
| --- | --- |
| `npm run dev` | Запускає сервер розробки з оновленням сторінки під час змін |
| `npm run build` | Створює production-версію сайту в каталозі `dist/` |
| `npm run preview` | Запускає локальний перегляд зібраної версії |
| `npm run format` | Форматує підтримувані файли за правилами Prettier |
| `npm run lint` | Запускає перевірку SCSS та форматування |
| `npm run lint:styles` | Перевіряє SCSS за правилами Stylelint |
| `npm run lint:format` | Перевіряє форматування без внесення змін |
| `npm run images` | Генерує оптимізовані варіанти зображень із каталогу `raw-images/` |

## Структура проєкту

```text
landing-keepsake-vite/
├── .github/workflows/       # автоматичне розгортання GitHub Pages
├── .husky/                  # Git hooks
├── scripts/                 # допоміжні скрипти
├── src/
│   ├── assets/images/       # зображення для сторінки
│   ├── components/          # повторно використовувані Pug-компоненти
│   │   └── sections/        # секції landing page
│   ├── data/                # дані для навігації та секцій
│   ├── includes/            # SVG-спрайт та інші підключення
│   ├── layouts/             # базові шаблони сторінок
│   ├── mixins/              # Pug-міксини
│   ├── pages/               # Pug-сторінки
│   └── styles/              # SCSS: abstracts, base, components, layout
├── package.json
├── postcss.config.js
└── vite.config.js
```

## Організація розмітки та стилів

- Pug-сторінка знаходиться в `src/pages/` і використовує базовий шаблон із `src/layouts/`.
- Спільні частини інтерфейсу винесені в `src/components/`, а повторювані фрагменти — у `src/mixins/`.
- Дані для окремих секцій зберігаються в `src/data/`, щоб не дублювати однакову розмітку.
- SCSS розділено за призначенням: базові стилі, змінні й міксіни, компоненти та структурні елементи сторінки.
- Основний файл стилів — `src/styles/main.scss`.

## Зображення

У розмітці використовуються адаптивні зображення з варіантами AVIF, WebP і JPEG. Міксин `picture` задає джерела різних форматів і ширин, щоб браузер міг обрати відповідний файл.

Для повторної генерації зображень додай вихідні JPG, PNG або WebP-файли до `raw-images/`, а потім виконай:

```bash
npm run images
```

Скрипт зберігає підготовлені файли в `src/assets/images/`.

## Публікація

Після push у гілку `main` GitHub Actions встановлює залежності, виконує `npm run build` і передає каталог `dist/` до GitHub Pages. Статус розгортання можна переглянути у вкладці **Actions** репозиторію.

Для цього в налаштуваннях репозиторію в розділі **Settings → Pages** має бути вибране джерело **GitHub Actions**.

## Браузери

Цільові браузери визначені у файлі `.browserslistrc`: останні дві версії Chrome, Firefox, Edge, Safari та iOS.
